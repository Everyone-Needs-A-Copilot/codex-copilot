# Parallel execution default: owner decision and evidence boundary

On 4 November 2026 the owner approved the complete parallel-orchestration plan: useful independent work should start by default after scope approval, converge under one accountable owner and finish with verified resource disposition. The owner also directed that standalone `/orchestrate` be deprecated and execution built into protocol. This supersedes the opt-in delegation decision ratified on 28 June 2026; SOUL's Hidden Worker boundary now forbids hidden, untracked or unowned workers rather than visible fan-out within approved work.

The former default was intentional, not an absent feature. An earlier benchmark recommendation had incorrectly treated zero subagents as a defect and attributed differences between whole frameworks to delegation without an identical-work comparison. That methodological correction remains valid. The present default changes because the owner changed the operating model, not because an unrun benchmark established a speed or quality result.

The implementation uses the existing shared `cc`/`tc` engine and a Codex-native adapter. Native capacity, resource permits, budgets, real design decisions, independent source-bound QA and safe retirement remain enforced boundaries. The owner subsequently explicitly authorized automatic removal of recorded eligible merged worktrees during cleanup after current identity, full integration, clean-state, inactivity, consumer and teardown checks. Branch history remains; dirty/unmerged/drifted/active/unknown work is held. There is no promise of unlimited simultaneous agents or a standing exception for all cycle-created resource deletion; the authorized merged-worktree exception is narrow.

The evidence question remains: how much does dependency-driven delegation improve elapsed time and quality on the same acceptance contract? `copilot-bench` retains its identical-brief delegating arm as a comparison instrument, and any paid run remains separately budgeted. Cheap deterministic role lifecycle checks prove start/record/release mechanics without model calls; a tiny live native run proves actual dispatch overlap. Neither alone proves higher-quality reasoning or end-to-end speed gains. Record negative results and setup/queue/merge overhead as well as successful overlap.

> Superseded in part (2026-11-05): the main session is now a coordinator only and dispatches same-role agents on disjoint partitions from the first turn, with approval gating only writes, outward actions and spending. See the parallel-execution skill.
