# Reviewed upstream adoption: Claude 5.33.0 to 5.34.0

Codex 0.16.0 adopts Claude Copilot 5.34.0 with cc 2.18.0 and tc 2.12.0. The reviewed functional source is foundation `ad6dbac95cb5a89d40e5b52ea0e674413d5fb457` and Codex `016039ec2fa977a31d28bff7fa170ae75e2fa29f`; CSE PRD4 / task10 preserves the implementation and independent installed-runtime acceptance. This is an explicit port, not an assertion that matching version numbers establish behavioral parity.

| Upstream change | Native disposition |
|---|---|

Preserve branch history, evidence and dirty, unique, active or uncertain work. Finish refuses unfinished tasks and active workers; task history is retained. |

| Release metadata | Root, plugin, catalog, both capability packs and the parity manifest agree on Codex 0.16.0. The mirrored framework and shared tool requirements are 5.34.0 / 2.18.0 / 2.12.0. |

## Publication boundary

The content manifest and its update log retain the reviewed implementation provenance until the actual foundation release commit is known. Compare content against the explicit 5.34.0 release checkout before updating either file; port any real shared-behavior drift first. A metadata-only refresh may use a specific no-port-needed attestation after confirming identical mirrored bytes, and its log must retain the explanation.

The release coordinator verifies the signed foundation `v5.34.0` commit/tag before recording its final identity, changes candidate metadata to released only when release readiness is established, and publishes Codex through its signed-main/tag procedure. Source adoption, tag publication and installed-consumer acceptance remain separate claims.
