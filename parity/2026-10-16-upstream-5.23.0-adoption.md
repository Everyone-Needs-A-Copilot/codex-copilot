# Reviewed upstream adoption: Claude 5.22.0 to 5.23.0

Scope: Claude Copilot 5.23.0 (cc 2.15.0, tc 2.7.0) against the 5.22.0 content baseline. The only mirrored delta is the rename of the work-lifecycle command and skill from `optimize` to `cleanup`; the lifecycle text itself changes only in the heading "Finish and clean up" and the command name.

| Upstream delta | Disposition |
|---|---|
| `commands/optimize.md` renamed to `commands/cleanup.md`; `skills/optimize/SKILL.md` renamed to `skills/cleanup/SKILL.md` | Ported: native skill `plugins/codex-copilot/skills/cleanup` (invoked as `$cleanup`). No `optimize` alias is kept. |
| `agents/_shared/work-lifecycle.md`: heading and explicit command name | Ported by `scripts/sync-work-lifecycle.py` into `skills/cleanup/references/work-lifecycle.md`. |
| `commands/protocol.md`: checkpoint sentence names a "cleanup command" | Ported: `skills/protocol/SKILL.md`, `AGENTS.md`, `templates/AGENTS.project.template.md`. |

## Boundaries

The `optimize:` protocol keyword and the `optimize` design verb are unrelated to this rename and unchanged. Earlier records and changelog entries keep the old name as history. Projects with an installed `plugins/codex-copilot/skills/optimize` copy must remove it by hand; the update path does not delete retired skills.
