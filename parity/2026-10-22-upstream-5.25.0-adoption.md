# Reviewed upstream adoption: Claude 5.24.0 to 5.25.0

Scope: Claude Copilot 5.25.0 (cc 2.15.1, tc 2.7.1, agents 5.10.0, commands 5.8.0), hashed at commit `21b85ff76e337d3584c78d1f95c043a6d4060815`, the head of the open pull request `feat/taste-p2-consumers` (claude-copilot PR 149). The 5.25.0 tag is pending, so this adoption is recorded against the pull request head and must be rechecked against the tagged release. Upstream changed three agents (`cco`, `cw`, `uids`) by adding a read-before-draft step and a keep/kill offer, renamed the personal taste file in four more (`sd`, `ta`, `ind`, `uxd`), and changed tests, evals and the context budget baseline.

| Upstream delta | Disposition |
|---|---|
| `cco`, `cw`, `uids` gain a Workflow step that calls the personal tier's `scripts/taste ref find --for-agent <id>`, plus a `Taste:` output line and a keep/kill verdict offer | Ported with the same wording to the Codex `uids` skill and to both copies of `cco` and `cw` under `packs/business-creative` and `packs/writing-legal`. The CLI is located only through `$CC_PERSONAL_KNOWLEDGE_REPO` after `eval "$(cc env)"`; the offer is a `## Taste Keep/Kill Offer` section because Codex skills run in the main thread and have no separate Output Format block. |
| `sd`, `ta`, `ind`, `uxd` name `08-taste/TASTE.md` instead of `08-taste/INDEX.md` | Ported to the Codex `sd`, `ta`, `ind`, `uxd` skills, and also to `uid`, which carries the same reader line. No fallback clause, as upstream. |
| Context budget ceiling raised, growth overrides added | Not mirrored: Claude-only byte budget for the agent corpus. |
| `tests/test_taste_consumers.py` and three `cc eval` golden cases | Mirrored as `tests/test_taste_consumers.py` for the five consumer skills and six readers, with a negative control per behaviour and CLI integration cases that skip where the personal tier is absent. The `cc eval` cases are not mirrored: Codex has no agent files for the runner. |
| Org overlays `claude-copilot-internal` `cco` and `codex-copilot-internal` `cco`, `uids`, `sd` | Out of scope here; separate tasks in the same initiative. |

The Codex core plugin has no `cco` or `cw`; only the dormant packs do, so the step reaches a project only when a pack is activated.
